# Site profile input

Each creator supplies their own profile as a separate file outside the shared skills. Do not assume a site identity from a prior creator's examples. Request missing essentials together; optional fields may be omitted.

- Site name and canonical URL.
- Audience, subject scope, tone and examples of published writing (or a local reference index).
- CMS and any HTML constraints. Default deliverables are HTML and Markdown; local image paths require manual CMS upload/relinking.
- Services/reader CTA: exact approved wording, destination and conditions; explicitly say none if not wanted.
- Disclosure rules and confirmed relationships for the current article. A profile cannot establish a relationship for every future article.
- TOC preference/style. Default: use the bundled styled TOC, one entry per H2 with matching section-N anchors.
- SEO conventions and internal-link sources, if available. Never invent existing pages or keyword performance.
- Optional image settings: native-resolution PNG by default, original framing/HUD, no overall color cast, no generated scene alterations. Captions optional; descriptive alt text required.
- Optional typical length and title-option count. Length must remain evidence-led and flexible; five relevant title options by default.

Do not store credentials, private paths or creator media in the reusable skill. Read only the selected creator's profile.
