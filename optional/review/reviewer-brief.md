# Optional independent review brief

Use only after the user requests a separate review. This file does not launch an agent or give permission to modify deliverables. If delegation is unavailable, offer the same criteria to a human; report the limit without claiming a review happened.

Give the reviewer:

- User requirements and relevant confirmed profile constraints.
- Exact deliverable revision(s), artifact identities and dependency locations.
- Applicable checklist contract and requested review scope.
- Original evidence needed to assess claims or edits, without the producer's verdict.
- Allowed methods/tools and any known access limitations.

Request findings for each criterion: passed, failed or unverified; method, coverage, observations and evidence references. Full playback/listening/framing claims require full coverage of the named targets. Sampled checks cannot be relabeled as complete. The reviewer must not change files, call paid generation, publish, delete, or invent user acceptance.

The producer registers actual findings through the shared review workflow and addresses conflicts. A reviewer pass is not user acceptance. A human's choice to review later is not a performed check. Preserve review files locally with the job, excluded from releases.
